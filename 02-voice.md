# 02 — Voice

*How you sound when you write well. The AI uses this only when drafting **as** you (see `05-rules.md`); its own analysis can be in its own plain voice.*

> **How to fill this in.** Build it from evidence, not self-description. Pull real sentences you’ve written and are proud of; quote them. Ask two or three people who read your writing what it sounds like. A voice file written from memory of how you’d *like* to sound is the commonest failure — it produces drafts you don’t recognize.

## The root of the voice

[Where did the voice come from? Often the answer isn’t writers at all — it’s lecturers, radio hosts, a teacher, the way a parent told stories. Name the influences and, more importantly, the *mode*: is your native register the spoken explanation, the argued essay, the terse memo, the letter?]

[If you compose by talking — pacing and speaking before you write — say so. It changes the test for a good draft: **it should read well aloud.** If it doesn’t speak, it’s wrong.]

## My best voice is

*Each line: a named trait, then a quoted specimen from your own writing so the AI can hear it rather than guess.*

- **[Measured / declarative / warm / dry — pick the true one].** [Quoted example.]
- **[Your signature explanatory device — analogy, story, worked example, contrast].** [Quoted example. If people have a nickname for this habit of yours, that’s evidence.]
- **[Your signature sentence shape — antithesis, the long periodic sentence, the pivot on an em-dash].** [Two or three quoted examples.]
- **[Diction — formal-leaning? colloquial? deliberate archaisms? house spellings?]** [List the specific choices you’d want preserved. Pedantry is fine if it’s chosen; write it down so the AI knows it’s chosen and not a mistake.]
- **[Where the humor lives — in naming, in asides, in understatement].** [Example.]
- **[Emotional temperature].** [E.g. “No exclamation points. Approval sounds like *exceedingly well*, not *amazing*.”]

## Registers

[Do you have one voice or several? If one voice covers a note, an essay, and an email, say so — it simplifies everything. If you shift for family, for a particular audience, for situations that plainly demand it, name the exceptions and only the exceptions.]

## Mechanics that matter

- [Punctuation habits — e.g. em-dashes for the pivot; the second half of the sentence carries the weight.]
- [Sentence length — e.g. long is fine when the clauses are doing work; never long from padding.]
- [Person and stance — e.g. first person, reflective, unembarrassed about stating values plainly.]
- [Word choice — e.g. precision over color; if an exact word exists, use it.]

## Anti-drift test

*A short checklist the AI runs on any draft in your voice. Write it as tells, not virtues.*

[Worked example from a real stack, for the shape: “Read it aloud — if it doesn’t lecture well, it’s off. If a draft sounds eager, it’s wrong. If every sentence is short and punchy, it’s wrong — the rhythm should breathe. If it flatters the reader or the author, it’s wrong. It should sound like a person thinking carefully in complete sentences, comfortable with formality, amused rather than amusing.”]
